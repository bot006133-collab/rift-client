Rift Client

A Windows launcher for Minecraft: Java Edition. Sign in with your own Microsoft account, keep each profile in its own instance, and play vanilla or Fabric.

Join the Rift Discord

How sign-in works

Rift uses the same sign-in sequence as other third-party launchers. It uses Microsoft's device-code flow: Rift shows a short code, and you enter it on microsoft.com/link in your own browser. Your password is only ever typed into Microsoft's page, never into Rift.

  1. MicrosoftDevice-code sign-in. Scopes: XboxLive.SignIn and XboxLive.offline_access.
  2. Xbox LiveThe Microsoft token is exchanged for an Xbox Live user token.
  3. XSTSXbox authorizes access to Minecraft services.
  4. Minecraft servicesRift requests a Minecraft access token from the launcher login endpoint.
  5. ProfileRift reads your Minecraft name and UUID, then launches the game you own.

What Rift stores

Everything stays on your PC. Rift has no server of its own and does not collect accounts, tokens or usage data.

  • Your Minecraft name and UUID, so the launcher can show who is signed in.
  • A Microsoft refresh token, encrypted with Windows DPAPI and tied to your Windows user, so you don't have to sign in on every launch.
  • Your instances and game files under %APPDATA%\Rift Client.

Rift is a public client. It contains no client secret, and it requests only the permissions listed above.

  • Signing out deletes the stored refresh token.
  • Access tokens are kept in memory and are hidden from the launch log.
  • Game files are downloaded from Mojang's official version metadata.

What it does

  • Installs Minecraft: Java Edition versions and the matching libraries and assets.
  • Creates separate instances, each with its own folder and mods directory.
  • Installs the Fabric mod loader for instances that want it.
  • Shows launch logs and crash details, with a repair option for damaged installs.
  • Shows your current game in Discord Rich Presence.

About this project

Rift Client only launches copies of Minecraft that the signed-in account already owns. It does not bypass ownership checks, offer cracked or offline play, or distribute Mojang's game files itself.
